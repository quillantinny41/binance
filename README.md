## 📝 Troubleshooting common issues

If you encounter problems during use, refer to these common fixes:

*   The application does not launch: Verify that you have the latest Microsoft .NET Framework installed.
*   No data appears on the screen: Check your internet connection. A firewall might block the software from reaching the market servers. Check your firewall logs to ensure the application has permission to access the web.
*   Slow performance: Close background programs that consume high amounts of memory.
*   Unable to connect to the exchange: Double-check that your API keys have correct permissions enabled on the exchange website.

If these steps do not fix the issue, restart your computer and try again. Clearing your temporary files can also help resolve performance lags.
